# 👗 ReWear Frontend (`odoofe`)

The React + TypeScript + Vite frontend client for the ReWear sustainable fashion exchange platform.

For the complete project overview, full architecture, and backend setup, please see the [Root README](../README.md).

---

## 🚀 Quick Start

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Environment Configuration**:
   Ensure `.env` contains:
   ```env
   VITE_API_BASE=http://localhost:8000
   ```

3. **Development Server**:
   ```bash
   npm run dev
   ```
   Runs locally at `http://localhost:5173`.

4. **Lint & Build**:
   ```bash
   npm run lint
   npm run build
   ```
